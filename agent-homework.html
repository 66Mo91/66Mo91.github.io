AI Agent (Work Buddy) 使用记录

人工智能概论｜姓名：莫祖乾

AI Agent 是具备感知、规划、调用工具能力的智能助手。下面记录我日常使用的各类智能体、使用场景与实际体验。

使用情况

初用Work Buddy

这是我第一次使用WorkBuddy，也是我第一次听说AI Agent，不知道它的功能有些什么。联想到我最近的任务，《费曼物理》的读书笔记，我便把要读的材料（一个PDF文档，大小大概800k）丢给了WorkBuddy，希望它能给我简要概况一些及指出其中的写作逻辑。第一次使用总有些差错，AI报错并显示找不到这个临时文件（ENOENT：no such file or directory)。

分析及调试

我搜索到以下原因：

1. Windows系统临时文件夹内的缓存文件被杀毒软件、系统机制自动清理

​2. 软件对临时目录的读写权限不足​

3.Agent调用文档解析技能时文件句柄丢失

于是我重新启动WorkBuddy，新建任务，选择日常办公-文档处理，从新发送PDF文档，并在桌面备份一份，权限选择允许完全访问，并将指令任务缩短，让其只用提取第一页的文字。可是还是显示出相同的报错

报错反馈

WorkBuddy作为AI Agent，文档解析功能依赖本地临时缓存文件。即便文件本身完好、预览正常，Windows系统、软件自身机制会造成临时文件丢失，导致Agent调用文档工具执行失败。 这体现AI Agent的短板：Agent不仅依赖大模型本身，还依赖本地操作系统、文件读写环境；环境异常会直接中断任务，和普通一次性问答AI相比，Agent调用外部工具会引入更多环境层面故障。

小结

之前我忽略了一个细节，也有可能是该文件是扫描图片版PDF，没有可复制文字，默认读不出来，需要OCR增强解析。为了绕开这一不足，我将文档内容提取文字，并复制给WorkBuddy，得到了最终结果。WorkBuddy给我生成了文档内容的主题、原因、定理内容及含义等简要概况，其生成速度和任务完成度都是很不错的
